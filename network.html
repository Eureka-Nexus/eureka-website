PROOF LAYERS

What can be verified.

Eureka Nexus separates public verification from sensitive infrastructure. Public addresses and network data are exposed; private keys and operator secrets are not.

01 · WORK

Accepted shares

CPU RandomX and GPU KAWPOW work is validated server-side. Invalid or merely reported work does not automatically generate entitlement.

02 · ACCOUNTING

Cumulative entitlement

Valid mining work contributes to wallet accounting before it becomes part of a published cumulative settlement.

03 · SETTLEMENT

2-of-3 operator signatures

Mining settlement publication requires the contract's operator threshold rather than a single arbitrary signer.

04 · PAYOUT

On-chain transaction

Automatic payouts create public BNB Smart Chain transaction evidence linked to the receiving miner wallet.

05 · SOFTWARE

Release verification

Official Miner releases are distributed through GitHub with SHA-256 checksums so downloaded files can be verified.

Public proof. Private secrets.
