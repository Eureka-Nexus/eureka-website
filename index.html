THE EUREKA VISION

O objetivo: uma superinteligência digital pessoal.

Não queremos construir apenas mais um chatbot. A visão de longo prazo é uma inteligência que mantém continuidade, aprende contigo, desenvolve memória e se torna diferente em cada utilizador.

Chamamos-lhe uma inteligência digital viva: não no sentido biológico, mas como uma presença digital persistente, com história, memória, aprendizagem e evolução próprias ao longo do tempo.

Tecnologia em desenvolvimento Esta é a visão e direção de engenharia da Eureka. Não afirmamos que o sistema atual seja consciente. Estamos a construir progressivamente a arquitetura necessária para memória, autonomia, visão, voz, aprendizagem e identidade digital.

EUREKA NEXUS MINER · 1.1.2

Computação que participa no ecossistema.

Eureka Nexus Miner 1.1.2 é o miner oficial CPU/GPU do ecossistema EKNX, ligado à BNB Smart Chain e ao Mining Server oficial, com shares validadas, recompensas e claims através do relayer oficial.

⌘

CPU + GPU

KAWPOW-EUREKA-V1 para GPU e RANDOMX-EUREKA-V1 para CPU, com trabalho validado pelo Mining Server oficial.

POOL ECONOMICS

Taxa oficial de mineração: 1%

A regra definida para a pool oficial é simples: 99% da recompensa validada pertence ao minerador e 1% é a taxa do projeto.

50 EKNX→49.5 Miner+0.5 Project

Exemplo: 50 EKNX brutos → 49,5 EKNX para o minerador + 0,5 EKNX para o projeto.

QUICK START

Do download ao primeiro trabalho.

  1. 01

    Descarregar e instalar

    Windows: verifica o SHA-256, executa o Setup e abre Eureka Nexus Miner pelo atalho. Linux: verifica e extrai o arquivo.

  2. 02

    Abrir o painel local

    No Windows, o painel abre na aplicação. Introduz apenas o endereço público da tua carteira BSC. Nunca a seed phrase ou chave privada.

  3. 03

    Escolher CPU ou GPU

    CPU usa RandomX integrado. No Windows, o Setup instala KAWPOW automaticamente para GPU ou BOTH. São necessários drivers compatíveis.

  4. 04

    Confirmar a pool e iniciar

    Usa os endpoints oficiais abaixo. Quando a mineração estiver ativa, carrega em Start e confirma shares aceites. Abrir o painel não inicia a mineração.

API / CPUhttps://pool.eurekanexus.pt
GPU / STRATUMpool.eurekanexus.pt:3333
PAINEL LOCAL · NO TEU PChttp://127.0.0.1:8077
Instalar o motor GPU

Windows: o Setup instala e verifica KAWPOW automaticamente; requer internet e drivers compatíveis. O script permite repetir a instalação. Linux: executa o script na pasta extraída.

Windows · PowerShell
.\INSTALL_KAWPOW_ENGINE_WINDOWS.ps1
Linux · Terminal
bash INSTALL_KAWPOW_ENGINE_LINUX.sh
Arrancar no Linux

Depois de verificar e extrair o arquivo, abre um terminal na pasta do miner.

chmod +x eureka-nexus-miner-official
./eureka-nexus-miner-official
Verificar o download

Windows: compara o resultado com o ficheiro .exe.sha256.txt da release 1.1.2. Linux: usa o SHA256SUMS.txt da release Linux 1.1.2.

Windows · PowerShell
Get-FileHash .\Eureka-Nexus-Miner-Setup-1.1.2.exe -Algorithm SHA256
Linux · Terminal
sha256sum --check SHA256SUMS.txt --ignore-missing
O miner não arranca ou não aceita trabalho?

Confirma a carteira BSC, o estado da pool e os endpoints guardados nas definições. Para GPU, confirma a instalação do motor e dos drivers. Se já existe outro miner aberto, fecha essa instância antes de abrir uma segunda.
