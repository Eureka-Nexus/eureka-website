# Eureka Nexus — Architecture

Eureka Nexus currently combines several layers.

## 1. Eureka AI

Persistent digital identity and future AI-agent platform.

## 2. Eureka 2026 Miner

Public CPU/GPU mining client.

## 3. Mining Server

Validates mining work, tracks rewards and feeds the payout architecture.

## 4. EKNX

BNB Smart Chain ecosystem token.

## 5. Automatic payout infrastructure

Validated mining rewards are settled through the official payout architecture.

## 6. Public network layer

Read-only public endpoints provide network information for the website and Miner.

## 7. Future Market layer

Planned architecture:

Launch Curve → liquidity preparation → DEX transition.

This layer is not currently public or active.

## 8. Future Eureka applications

Planned layers include:

- Eureka AI desktop experience
- Mobile experiences
- Specialised agents
- Eureka AI Capital Agent
- EKNX-supported ecosystem services
