## Automatic payouts

Eureka Nexus uses automatic EKNX payout infrastructure.

The public Miner does not require the user to perform a manual on-chain claim.

Minimum payout currently used by the production architecture:

**5 EKNX**

## Security

The official Miner must only require a public BSC wallet address.

Never enter:

- Seed phrase
- Private key
- Keystore password
- Exchange credentials
- API secrets

into mining software.
