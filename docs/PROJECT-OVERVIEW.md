# Eureka Nexus — Project Overview

## Beyond Crypto. Beyond AI.

Eureka Nexus is a Portuguese technology project combining:

- Eureka AI
- Eureka Nexus Mining Network
- Eureka 2026 Miner
- EKNX
- Future AI agents and applications
- A future EKNX market layer

The project is not intended to be only a cryptocurrency project and is not intended to be only another chatbot.

The long-term objective is to build a persistent and personalised digital intelligence ecosystem in which each user can shape their own Eureka.

## Eureka AI

Eureka AI is being developed around:

- Persistent identity
- User-defined appearance
- User-defined personality
- Voice
- Permission-based vision
- Long-term memory
- Goals and planning
- Tools and agents
- Files and applications
- Research
- Automation
- Personal digital continuity

Eureka Nexus does not claim that the current Eureka system is conscious or sentient.

## Infrastructure already operating

The project already includes real infrastructure:

- EKNX contract on BNB Smart Chain Mainnet
- Eureka Nexus Mining Server
- CPU mining through RANDOMX-EUREKA-V1
- GPU mining through KAWPOW-EUREKA-V1
- Public mining network endpoints
- Server-validated shares
- Automatic EKNX payouts
- Eureka 2026 1.0 Miner for Windows and Linux
