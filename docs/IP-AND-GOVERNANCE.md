# Eureka Nexus — Intellectual Property and Repository Governance

## Repository model

The Eureka Nexus public repositories are intended to provide:

- Transparency
- Technical verification
- Public documentation
- Reproducible release information
- Security review
- Controlled collaboration

Public source visibility does not automatically mean that Eureka Nexus
is open source.

The applicable repository licence must always be checked.

## Original Eureka Nexus work

Original project material may include:

- Software
- Architecture
- Documentation
- Website content
- Visual design
- Branding
- Protocol designs
- Mining integrations
- Eureka AI concepts and implementations
- EKNX-related technical implementations

Ownership and protection remain subject to applicable law and the
rights described in the repository licence and copyright notices.

## Third-party materials

Eureka Nexus may depend on third-party software.

Each third-party component remains governed by its own licence.

The project must preserve legally required:

- Copyright notices
- Licence notices
- Attribution
- Source obligations
- Modification notices

where applicable.

## Branding

Names and branding include, among others:

- Eureka Nexus
- Eureka AI
- Eureka 2026
- EKNX

Publication in GitHub does not grant third parties permission to imply
that an unofficial project is an official Eureka Nexus product.

## Official source of truth

Production information should be verified against official project
sources.

Primary public sources include:

- https://eurekanexus.pt
- https://github.com/Eureka-Nexus

For blockchain data, users should additionally verify information
directly on the relevant blockchain explorer.

## Documentation status

Documents may use status markers such as:

- LIVE
- ACTIVE
- COMING SOON
- PLANNED
- IN DEVELOPMENT
- DRAFT

A planned feature must not be interpreted as deployed solely because it
is described in documentation.

## Market documentation

Launch Curve and future DEX documentation describe planned project
architecture unless explicitly marked as active.

Market activation requires completion of the applicable technical,
security and legal launch gates.

## Governance

Until a separate formal governance structure is publicly established,
official project decisions and production releases are determined
through the Eureka Nexus project maintainership.

No token-holder voting or decentralised governance mechanism should be
assumed unless one is explicitly implemented and documented.

## Contributions

Contributions may be accepted subject to:

- Repository licence
- Security requirements
- Project architecture
- Contributor rights
- Review and approval

A pull request does not become part of the official project until it is
accepted and merged by an authorised maintainer.

## Legal status

This governance document is public project documentation.

It does not replace professional legal advice, corporate documentation,
regulatory filings or intellectual-property registration procedures.
