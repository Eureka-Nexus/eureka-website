INSTALAÇÃO NO TEU WINDOWS / WSL:
1. Extrai este ZIP em C:\EurekaNexus\
   Deve criar C:\EurekaNexus\Eureka_Nexus_Website_2_1_PT_EN\
2. No WSL executa:
   bash /mnt/c/EurekaNexus/Eureka_Nexus_Website_2_1_PT_EN/deployment/install-into-website.sh
3. O script:
   - verifica a main original e backup do Git
   - cria um worktree e branch isolados
   - substitui os ficheiros antigos apenas NA NOVA BRANCH
   - testa HTML, links, versões PT/EN e JavaScript
   - faz commit e push da branch de revisão
   - NÃO altera a main nem a produção
4. Consulta o link de comparação que o script indicar.
5. Abre o novo site localmente em WSL:
   cd /mnt/c/EurekaNexus/Eureka_AI_Website_2_Bilingual_Preview
   python3 -m http.server 8765
   Em Windows, abre http://localhost:8765/ e http://localhost:8765/en/
6. Rever o conteúdo (jurídico, economia futura e contactos), imagens, vídeo e navegação.
7. Só depois aprovar merge na branch main, que alimenta GitHub Pages.
