# Media real do programa Eureka

O website não apresenta fotografias, capturas de ecrã ou vídeos falsos como se fossem do programa real.

Para adicionar materiais aprovados, copia os ficheiros finais para esta pasta e adiciona registos ao `manifest.json`:

```json
[
  {"file": "eureka-chat-01.webp", "title": {"pt": "Interface real do chat Eureka", "en": "Real Eureka chat interface"}},
  {"file": "eureka-demo-01.mp4", "title": {"pt": "Demonstração real da aplicação", "en": "Actual application demonstration"}}
]
```

Apenas nomes de ficheiros locais (sem caminhos) com extensões webp/png/jpg/jpeg/mp4/webm. Evita informações privadas, endereços de servidores, credenciais e dados pessoais nas capturas. Obtém consentimento para rostos, vozes e dados de terceiros. Faz revisão manual antes de publicar.
