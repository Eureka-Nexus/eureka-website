Privacy by design.

Resumo de privacidade do site Eureka Nexus. Atualizar antes de ativar analytics, formulários, contas ou serviços que recolham dados pessoais.

Português

Esta versão do site é essencialmente informativa e estática. Não deve pedir seed phrases, chaves privadas ou credenciais de carteira. Se forem adicionados formulários, analytics, newsletters, contas de utilizador, pagamentos ou cookies não essenciais, esta política deve ser atualizada antes da ativação.

Endereços públicos de blockchain apresentados no site são informação pública. Ao abrir BscScan, GitHub ou outros serviços externos, aplicam-se as políticas desses serviços.

Questões de privacidade: contact@eurekanexus.pt.

English

This version of the website is primarily informational and static. It should never request wallet seed phrases, private keys or wallet credentials. If forms, analytics, newsletters, user accounts, payments or non-essential cookies are added, this policy must be updated before those features go live.

Public blockchain addresses displayed by the site are public information. When visitors open BscScan, GitHub or other external services, those services' policies apply.

Privacy questions: contact@eurekanexus.pt.
